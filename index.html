☀ DSC Player Companion

The full static app (character sheets, DSC classes, sessions, notes, dice, Open5e spells/equipment sync) is packaged as DSCPlayer-Companion.zip.

To publish this repo:

unzip DSCPlayer-Companion.zip
cd dsc-player-companion
# copy contents into the repo root (over this placeholder)
git add -A
git commit -m "Add full Player Companion app"
git push

Then enable Settings → Pages (GitHub Actions workflow is included).
